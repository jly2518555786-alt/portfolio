##分享我探索金融业务和ai结合的过程

最初是从想在工作的业务场景，将一些可固定下来的业务逻辑标准化，提升团队的工作效率，才萌发了vibe coding做产品的需求。
当我真正开始搭建产品、构建 **Agent Skills** 时，我很快发现：AI 可以大幅降低写代码的门槛，却不会替代对计算机系统的理解。诸如此类的问题在我的脑中涌现：

* 后端数据库怎么搭建，什么样的结构能更好的满足需求？
* 提示词怎么优化，能让ai充分地理解我的意图？
* Context engineering 怎么做？该输入什么样地信源？信源事实类型？信源优先级？如何优化上下文本记忆能力问题？
* 该如何为项目创造出一个更好的约束环境？claude.md,agent.md如何编写，在项目内指令和原则，你是谁、你做事的原则、你希望AI用什么方式跟你协作？

沿着全栈工程师的知识体系持续补课，也开始阅读计算机史和计算机科普书籍，我的工程化ai的笔记将持续分享：[工程化 AI 知识库](https://jly2518555786-alt.github.io/portfolio/engineering-ai.html)

希望亲手使用AI、理解它、构建它，并通过技术杠杆，使得一个个作品在真实的市场中去解决市场的问题，客户的需求，放大产品的价值。
就我目前的理解而言，由于金融市场是一个注重信息获取的速度和质量的领域，因此ai的辅助确实很有必要（要判断什么样的场景值得自动化提效）
# 金融AI八大业务方向

| 序号 | 按业务分类 | 核心客户 | 典型 Agent | 难点 |
|---|---|---|---|---|
| 1 | 金融交易与投资 | 券商、资管机构 | 交易 Agent、投研 Agent | 卷不过别人相当于没搞。对于研发要求高 |
| 2 | 财富管理 | 银行、券商、基金销售机构 | 客户财富管理 Agent（包含客户画像分析，如何营销获客） | |
| 3 | 金融租赁/融资租赁 | 银行、消费金融、金融租赁公司 | 企业财务状况分析 Agent、融资 Agent | 中小企业财务非公开 |
| 4 | 风险管理与反洗钱 | 银行、券商、期货、支付机构 | AML Agent、反欺诈 Agent | |
| 7 | 支付与资金管理 | 支付机构、银行、跨境企业 | 支付风控 Agent、资金管理 Agent | |
| 8 | 金融基础设施 | 银行、券商、基金、资管机构 | 数据治理 Agent、智能运维 Agent | 要求可追溯，责任可对应。目前难实现100%准确 |





目前，我在利用 AI沿着上图中的方向探索适合我的发力点， 完成的项目 demo、产品探索，都记录在我的简历和个人 GitHub 主页中。它们未必成熟，但每一项都是我真实做过、踩过坑、迭代过的东西。
欢迎各位老师查看和指点。对我来说，真正有意思的事情才刚刚开始。
